# AutoCloud

AutoCloud は、AutoCAD 上のブロック参照を対象に、外接範囲を取得して長方形状の雲マークを自動作成する C# / AutoCAD .NET API 用ツールです。

現行版 `AutoCloud_ver4.cs` では、`AutoCloud_ver3.cs` の範囲選択・表示画層判定機能を引き継ぎつつ、処理内容と対象物を明確に分離し、任意に選択したブロック参照だけを対象にする機能を追加しています。

---

## 現行バージョン

- 現行コード: `AutoCloud_ver4.cs`
- 前バージョン: `AutoCloud_ver3.cs`
- コマンド名: `CHECKCLOUD`

---

## AutoCloud_ver4.cs の概要

`AutoCloud_ver4.cs` では、フォーム内の設定項目を以下の3グループに整理しています。

```text
処理内容
対象物
オプション
```

これにより、以下を分けて指定できます。

```text
どの処理を行うか
どのブロック参照を対象にするか
どの補助条件を使うか
```

---

## AutoCloud_ver4.cs の主な機能

### 処理内容

以下の3種類の処理を選択できます。

```text
ブロック参照：位置合わせ
ブロック参照：個別
ブロック参照：全体
```

#### ブロック参照：位置合わせ

対象ブロック参照の外接範囲を比較し、外接範囲同士が接している、または指定した許容距離以内にある場合、同じグループとして扱います。

例：

```text
A と B が近い
C は離れている
```

この場合、以下のように雲マークを作成します。

```text
A+B の統合雲マーク
C の単独雲マーク
```

また、A と B、B と C が連続して近い場合は、A・B・C を1つのグループとして扱います。

#### ブロック参照：個別

対象ブロック参照ごとに、個別の雲マークを作成します。

#### ブロック参照：全体

対象ブロック参照すべての外接範囲を1つに統合し、全体を囲む雲マークを1つ作成します。

この処理は、`AutoCloud_ver3.cs` 以前の「図面全体」に近い処理ですが、対象は図面内の全図形ではなく、ブロック参照のみです。

---

## 対象物

以下の3種類から処理対象を選択できます。

```text
図面全体
範囲選択をしたブロックのみ対象
選択したブロック参照のみ対象
```

### 図面全体

ModelSpace 内のすべてのブロック参照を対象にします。

範囲選択やオブジェクト選択を行わず、自動的に図面全体のブロック参照を処理します。

### 範囲選択をしたブロックのみ対象

作成ボタンを押したあと、AutoCAD 上で2点を指定します。

指定した範囲に入る、または範囲にかかったブロック参照のみを対象にします。

内部処理では `SelectCrossingWindow` を使用しているため、範囲に少しでもかかったブロック参照も対象になります。

### 選択したブロック参照のみ対象

`AutoCloud_ver4.cs` で追加した機能です。

作成ボタンを押したあと、AutoCAD 上で任意のブロック参照を選択します。

選択後に Enter、または右クリック確定を行うと、選択されたブロック参照のみを対象にして雲マークを作成します。

---

## オプション

以下のオプションを指定できます。

```text
表示中の画層のみ対象
既存雲マークを削除してから作成
```

### 表示中の画層のみ対象

ON の場合、以下の画層にある図形を対象外にします。

```text
OFF 画層
フリーズ画層
*_check 画層
```

ブロック参照については、ブロック参照自体の画層だけでなく、ブロック内部の図形の画層も確認します。

そのため、ブロック内部に非表示画層の図形が含まれていても、表示中の図形だけを対象に外接範囲を計算できます。

### 既存雲マークを削除してから作成

ON の場合、実行日のチェック画層上にある既存の雲マークを削除してから、新しい雲マークを作成します。

削除対象は、当日チェック画層上の `Polyline` です。

---

## 画層仕様

雲マークは、実行日の日付を使った専用画層に作成されます。

形式：

```text
yyyyMMdd_check
```

例：

```text
20260604_check
```

作成される画層の色は赤色です。

## 数値設定

### オフセット量

取得した外接範囲から、どれだけ外側に雲マークを広げるかを指定します。

例：

```text
100
```

の場合、外接矩形から外側に 100 図面単位分広げた位置に雲マークを作成します。

### 雲マーク山ピッチ

雲マークの山の間隔を指定します。

値が小さいほど細かい雲マークになり、値が大きいほど粗い雲マークになります。

### 位置合わせ許容

ブロック参照同士を同じグループとして扱う距離を指定します。

外接範囲同士の最短距離がこの値以下の場合、同じグループとして扱います。

## AutoCloud_ver3.cs から AutoCloud_ver4.cs への変更内容

### 1. 処理内容と対象物を分離

`AutoCloud_ver3.cs` では、以下のように処理対象と処理モードがやや混在していました。

```text
ブロック参照：位置合わせグループ
ブロック参照：個別
図面全体
範囲選択したブロックのみ対象
```

`AutoCloud_ver4.cs` では、設定項目を以下のように整理しています。

```text
処理内容:
ブロック参照：位置合わせ
ブロック参照：個別
ブロック参照：全体

対象物:
図面全体
範囲選択をしたブロックのみ対象
選択したブロック参照のみ対象

オプション:
表示中の画層のみ対象
既存雲マークを削除してから作成
```

これにより、処理内容と対象範囲を組み合わせて指定できるようになりました。

---

### 2. 旧「図面全体」を「ブロック参照：全体」に整理

`AutoCloud_ver3.cs` までの「図面全体」は、実質的に対象ブロック参照全体を囲む処理として使われていました。

`AutoCloud_ver4.cs` では、この処理を `ブロック参照：全体` として整理しています。

一方で、`図面全体` は対象物の指定として扱います。

```text
図面全体
= ModelSpace 内のすべてのブロック参照を対象にする

ブロック参照：全体
= 対象ブロック参照すべてを1つの雲マークで囲む
```

---

### 3. 選択したブロック参照のみ対象を追加

`AutoCloud_ver4.cs` では、新たに以下の対象指定を追加しました。

```text
選択したブロック参照のみ対象
```

この機能では、作成ボタンを押したあとに AutoCAD 上でブロック参照を選択し、Enter または右クリックで確定します。

選択されたブロック参照だけが処理対象になります。

---

### 4. オブジェクト選択後の表示残りを修正

オブジェクト選択時、右クリックを Enter 確定として使用すると、AutoCAD 画面上に選択プロンプトの表示が残る場合がありました。

`AutoCloud_ver4.cs` では、以下の対策を入れています。

```text
PromptSelectionOptions.MessageForAdding を使用しない
ed.GetSelection(filter) のみで選択取得
選択後に即時クリア
0.2秒後に遅延クリア
0.7秒後に遅延クリア
```

通常は `Regen()` を使わず、`UpdateScreen()` を中心に表示を更新します。

これにより、右クリック確定時の表示残りを抑制しています。

---

### 5. 選択 ObjectId の重複除外

範囲選択およびオブジェクト選択で取得した `ObjectId` は、`HashSet<ObjectId>` を使って重複を除外しています。

---

### 6. 画層表示判定のキャッシュ化

表示中画層判定で、同じ画層を何度も確認しないように、`Dictionary<ObjectId, bool>` を使用して判定結果をキャッシュしています。

これにより、`表示中の画層のみ対象` が ON の場合の処理負荷を軽減しています。

## 使用方法

1. AutoCAD を起動します。
2. `NETLOAD` コマンドでビルド済み DLL を読み込みます。
3. AutoCAD のコマンドラインで以下を実行します。

```text
CHECKCLOUD
```

4. 表示されたフォームで、処理内容・対象物・オプションを選択します。
5. `作成` ボタンを押します。
6. 対象物の設定に応じて、必要な選択操作を行います。
7. 条件に応じて雲マークが自動作成されます。

---

## 推奨設定

通常の確認作業では、以下の設定がおすすめです。

```text
処理内容:
ON  ブロック参照：位置合わせ
OFF ブロック参照：個別
OFF ブロック参照：全体

対象物:
ON  図面全体

オプション:
ON  表示中の画層のみ対象
ON  既存雲マークを削除してから作成
```

部分的に確認したい場合は、対象物を以下のどちらかに変更します。

```text
範囲選択をしたブロックのみ対象
選択したブロック参照のみ対象
```

## 処理概要

AutoCloud の基本的な処理の流れは以下です。

```text
CHECKCLOUD 実行
↓
フォーム表示
↓
処理内容・対象物・オプションを取得
↓
必要に応じて範囲選択またはオブジェクト選択
↓
対象ブロック参照を取得
↓
表示画層条件を反映
↓
外接範囲を計算
↓
処理内容に応じて範囲を統合または分割
↓
雲マーク用画層を作成
↓
既存雲マークを削除
↓
Polyline の bulge を使って雲マーク作成
↓
作成数・削除数を表示
```

---

## 注意点

### 同日チェック画層上の Polyline

既存雲マーク削除処理では、当日チェック画層上の `Polyline` を削除対象とします。

そのため、同じ画層に手動で作成した `Polyline` がある場合、それも削除される可能性があります。

運用上、`yyyyMMdd_check` 画層は AutoCloud 専用として使用することを推奨します。

### 表示中画層のみ対象の処理負荷

`表示中の画層のみ対象` が ON の場合、ブロック内部の図形を走査して外接範囲を計算します。

そのため、ブロック数が多い図面や、ブロック内部の図形数が多い図面では、通常より処理時間が長くなる可能性があります。

### Dynamic Block

Dynamic Block は、多くの場合で外接範囲を取得できますが、Visibility State や内部定義の状態によっては、意図しない範囲を取得する可能性があります。

### Xref

現時点では、外部参照内の図形を細かく判定する処理には明確には対応していません。

### PaperSpace

現時点では、主に ModelSpace を対象としています。

PaperSpace 上の図形やビューポート内図形は対象外です。
